## 0. Decisions at a glance

| Topic | Decision |
|---|---|
| App shape | A Vite + TypeScript web plugin with no UI framework, built with pnpm. It runs inside the Even Realities app's WebView and draws text on the G2 through `@evenrealities/even_hub_sdk` **0.0.16** (pinned exactly). |
| Fetching Substack | Through **our own stateless, GET-only relay**, required for three reasons: Substack sends no CORS headers **[verified]**, SDK 0.0.16 has no native fetch, and Even's docs say to "proxy through a server you control". The relay is one ESM Worker file: deploy it to the owner's Cloudflare account (default) or the owner's OpenAI Sites. Its origin is baked in at build time and added to the `network` whitelist at pack time, which is the same pattern LIHKG uses. |
| Substack data sources | All undocumented web-app endpoints, all public, with no login:<br>• `GET {host}/api/v1/archive` for lists<br>• `GET {host}/api/v1/posts/{slug}` for post bodies<br>• `GET substack.com/api/v1/posts/by-id/{id}` for share links<br>• `GET substack.com/api/v1/top/search?query=` for name search (`publication/search` returns empty results unless the User-Agent is a browser's; we will not spoof one) **[verified]**<br>• `GET substack.com/api/v1/user/{handle}/public_profile` to import a user's public subscriptions<br>• `GET {host}/feed` as a fallback |
| HTML → text | Converted **on the phone** with `DOMParser`, starting from the research reference implementation `04-htmlToReaderText.ts`. The relay only trims JSON and passes `body_html` through unchanged. |
| Glasses layout | One fixed layout with 3 text containers (title, body that captures input, footer). It is created once, and every later update is `textContainerUpgrade` only. **The app never calls `rebuildPageContainer`.** Menus are text with a `>` cursor; the native ListContainer is not used. |
| Pagination | Copy LIHKG `pagination.ts`, which uses pretext `measureTextWrap` on a 544 px × (lines × 27 px) box with a 1800 UTF-8 byte cap. Add page start offsets so the reading position is stored as a character offset. |
| Gestures | Swipe down (`SCROLL_BOTTOM`) moves next or down. Swipe up (`SCROLL_TOP`) moves previous or up. Tap opens, or turns to the next page in the reader. **Double-tap goes back**; on Home it calls `shutDownPageContainer(1)`. Long-press is also treated as back, except on Home. A phone setting can invert swipe direction. |
| Persistence | Bridge storage (`setLocalStorage`/`getLocalStorage`) is the source of truth, with `window.localStorage` as a mirror. Data is split into two keys, each kept under 48 kB. |
| Content scope | Free posts are shown in full. Paid posts show Substack's public preview followed by a clear "preview ends" card. No cookies, no login, and article text is never stored on the server or persistently on the device (an in-memory cache for the session only). |
| Language | English only (`supported_languages: ["en"]`). |
| Testing | Follows the owner's rule: **runtime tests run only in GitHub Actions** (every script throws unless `CI==='true'`). Locally the implementer only installs, type-checks, builds and packs. |
| Local toolchain | A portable **Node v22.23.3 exists at `C:/Code/.tools/node`** (with npm 10.9.9 and a corepack `pnpm` shim) but is not on PATH. This contradicts the brief's "Node not installed". Use it to create `pnpm-lock.yaml` and to run `check`/`build`/`pack`. |

## 1. Architecture (diagram in words)

```
[G2 glasses 576x288, 4-bit green]  <-- BLE (Even app) -->  [Even Realities app on phone]
        ^ text containers only                                  |
        | SDK: createStartUpPageContainer (once),               | hosts WebView (Android Chromium / iOS WKWebView)
        |      textContainerUpgrade, shutDownPageContainer(1),   v
        |      onEvenHubEvent, set/getLocalStorage, onLaunchSource
        |                                     [Plugin .ehpk: index.html + JS bundle]
        +------------------------------------  src/glasses.ts  (bridge wrapper, one serialized write queue)
                                              src/app/controller.ts (glasses state machine)
                                              src/phone/*         (phone UI: publications, browse, settings, diagnostics)
                                              src/substack/html.ts (DOMParser -> reader text)  src/pagination.ts (pretext pages)
                                              src/storage.ts      (bridge KV + localStorage mirror)
                                              src/substack/api.ts (relay client: GET, credentials:'omit', no custom headers)
                                                         |
                                                         | HTTPS GET (simple CORS request, no preflight)
                                                         | origin MUST equal app.json network.whitelist[0]
                                                         v
                                [Relay  https://<relay-origin>]  worker/relay.ts  (Cloudflare Worker or Sites)
                                 - fixed routes /v1/{health,archive,post,profile,search,feed}
                                 - host allowlist (*.substack.com | substack.com for 3 templates | custom domain with DoH CNAME check)
                                 - honest UA, redirect:'manual' (<=3 hops, same path), 10 s timeout, streaming size caps
                                 - requires x-served-by: Substack | x-cluster: substack on every upstream response
                                 - trims JSON, adds Access-Control-Allow-Origin: *, short edge cache, no logs, no storage
                                                         |
                                                         v
                                [Substack]  <sub>.substack.com | custom domains | substack.com/api/v1/...
```

Data flow when the user reads a post:
1. The user taps a post in a glasses list.
2. The controller immediately renders `Loading…` on the glasses.
3. `api.getPost({host, slug})` calls `GET relay/v1/post?host=&slug=`. The relay fetches Substack and returns `{post:{…, bodyHtml}}`.
4. `buildArticle()` calls `htmlToReaderText()` and adds a header block.
5. `paginate()` splits the text into pages, each with a start offset.
6. The resume offset maps to a page, and the page is rendered as `{title, body, footer}`.
7. After the glasses accept the write, the position is saved (debounced 800 ms).

### 2.7 `vite.config.ts`

```ts
import { defineConfig, type Plugin } from 'vite'
import { readFileSync } from 'node:fs'

const { version } = JSON.parse(readFileSync(new URL('./package.json', import.meta.url), 'utf8'))
const raw = (process.env.VITE_RELAY_ORIGIN || '').trim()
const relayOrigin = raw ? new URL(raw).origin : ''

function buildInfo(): Plugin {
  return { name: 'reader-build-metadata', generateBundle() {
    this.emitFile({ type: 'asset', fileName: 'build-info.json', source: JSON.stringify({ version, relayOrigin }) })
  } }
}

/** Dev only (owner-run QR sideload): serve the relay at same-origin /relay so no CORS/whitelist applies. */
function devRelay(): Plugin {
  return { name: 'dev-relay', apply: 'serve', configureServer(server) {
    server.middlewares.use('/relay', async (req, res) => {
      const mod = await server.ssrLoadModule('/worker/relay.ts')
      const r: Response = await mod.default.fetch(new Request('https://dev-relay.invalid' + (req.url || '/'), { method: req.method }))
      res.statusCode = r.status
      r.headers.forEach((v, k) => res.setHeader(k, v))
      res.end(Buffer.from(await r.arrayBuffer()))
    })
  } }
}

export default defineConfig({
  base: './',                                   // packaged app loads from a local package, not a web root
  build: { target: 'es2022', sourcemap: false },
  server: { host: true, port: 5173 },
  plugins: [buildInfo(), devRelay()],
})
```

### 2.9 `scripts/check-relay-origin.mjs`

- Reads `process.env.VITE_RELAY_ORIGIN`.
- Empty: prints `configured=false`. With `--require`, it throws "Set repository variable VITE_RELAY_ORIGIN to the deployed relay origin."
- Set: validates exactly as the LIHKG CI inline script does:
  - `https:`;
  - no credentials, search or hash, and `pathname === '/'`;
  - hostname not matching `/(^|\.)(localhost|example\.(com|net|org)|invalid|test)$/`;
  - not `127.*`, `0.0.0.0` or `[::1]`.

  It throws if invalid, otherwise prints `configured=true`.

### 2.10 `scripts/pack.mjs` (adapted from LIHKG)

```js
import { mkdir, readFile, writeFile, readdir, cp, rm } from 'node:fs/promises'
import { execFileSync } from 'node:child_process'
import path from 'node:path'

const raw = process.env.VITE_RELAY_ORIGIN
let url
try { url = new URL(raw) } catch { throw new Error('Set VITE_RELAY_ORIGIN to the deployed HTTPS relay origin before building and packaging.') }
if (url.protocol !== 'https:' || url.username || url.password || url.search || url.hash || url.pathname !== '/' ||
    /(^|\.)(localhost|example\.(com|net|org)|invalid|test)$/.test(url.hostname)) throw new Error('VITE_RELAY_ORIGIN must be a bare public https origin.')
const manifest = JSON.parse(await readFile('app.json', 'utf8'))
const pkg = JSON.parse(await readFile('package.json', 'utf8'))
const buildInfo = JSON.parse(await readFile('dist/build-info.json', 'utf8'))
if (manifest.version !== pkg.version) throw new Error('app.json version must equal package.json version.')
if (buildInfo.relayOrigin !== url.origin || buildInfo.version !== manifest.version) throw new Error('Build origin/version does not match. Rebuild before packaging.')
const whitelist = [url.origin]
if (process.env.ENABLE_RSS2JSON_FALLBACK === '1') whitelist.push('https://api.rss2json.com')   // off by default (owner decision)
manifest.permissions = [{ name: 'network', whitelist,
  desc: 'Loads public Substack posts through the Reader for Substack relay service' + (whitelist.length > 1 ? ' and, if it is unavailable, the rss2json feed converter.' : '.') }]
const staging = path.resolve('artifacts/package')
if (!staging.startsWith(path.resolve('artifacts') + path.sep)) throw new Error('Unsafe staging directory.')
await rm(staging, { recursive: true, force: true })
await mkdir(staging, { recursive: true })
for (const name of await readdir('dist')) {
  if (['server', '.openai', 'worker.mjs', '_appgen_meta'].includes(name)) continue
  await cp(path.join('dist', name), path.join(staging, name), { recursive: true })
}
await writeFile('artifacts/app.json', JSON.stringify(manifest, null, 2) + '\n')
const cliPkg = JSON.parse(await readFile('node_modules/@evenrealities/evenhub-cli/package.json', 'utf8'))
const bin = typeof cliPkg.bin === 'string' ? cliPkg.bin : cliPkg.bin.evenhub
execFileSync(process.execPath, [path.resolve('node_modules/@evenrealities/evenhub-cli', bin), 'pack',
  'artifacts/app.json', 'artifacts/package', '--sdk-ver', '0.0.16', '-o', `artifacts/substack-reader-${manifest.version}.ehpk`], { stdio: 'inherit' })
```

### 4.5 Data loading rules

- **Latest:**
  - Take the first `latestMaxPublications` publications with `inLatest` set.
  - Fetch `getArchive(host, {limit: 12})` for each, 2 at a time.
  - Merge by `postDate` descending, dedupe by id, and keep the first 50.
  - Partial failures still show the posts that did load. The footer adds `· 2 failed` when publications failed.
  - Cache the merged result in memory for 5 min.
  - Latest has no "Load older" row.
- **Publication list:** archive `offset=0, limit=12`. "Load older posts…" appears while `nextOffset != null`.
- **Feed fallback:** if the archive fails with `UPSTREAM_BLOCKED`, `UPSTREAM_RATE_LIMITED` or `UPSTREAM_UNAVAILABLE`, try `getFeedXml(host)` once. On success, show its posts and keep the feed bodies in memory, so opening those posts uses the cached HTML.
- **Reader:**
  - Fetch with `getPost({host, slug})`; if the ref has only an id, use `getPost({id})`.
  - If `meta.host` differs from the stored host, update the stored publication and PostRef host (redirect to a custom domain).
  - Converted articles are cached in a memory LRU of 10 entries.
- **Resume:**
  - If `Position.version` equals the current version, open `pageIndexForOffset(pages, offset)`.
  - Otherwise open `round(fraction * pages.length)`. This covers a converter or density change.
- **Saving the position:**
  - Save after **each successful render** of a reader page, debounced 800 ms.
  - `store.flush()` immediately on back, opening another article, `background`, `pagehide`, `visibilitychange: hidden` and `exitApp`.
  - Write `lastOpen` once per article open.
- **Launch:**

  - Otherwise stay on Home.

- **No polling and no prefetch in v0.1.** All fetches are on demand.

## 6. Relay API contract (protocol 1)

All routes are `GET`. `OPTIONS` returns 204; any other method returns 405 `METHOD_NOT_ALLOWED`.

Headers on **every** response:
- `Access-Control-Allow-Origin: *`
- `Access-Control-Allow-Methods: GET, OPTIONS`
- `Access-Control-Max-Age: 86400`
- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: no-referrer`
- `Content-Type: application/json; charset=utf-8` (the feed route uses XML)
- `Cache-Control: public, max-age=<client TTL>` on success, `no-store` on errors

Never send `Access-Control-Allow-Credentials` and never copy `Set-Cookie`.

Envelope: `{ok:true, data, meta:{host, cached, fetchedAt}}` or `{ok:false, error:{code, message, retryAfterSeconds?, upstream?:{status, contentType, challenge}}}`. Upstream bodies and headers are never echoed.

| Route | Upstream (built server-side) | Edge / client TTL | `data` |
|---|---|---|---|
| `/` and `/privacy` | none | 3600 | HTML landing and privacy text. CSP `default-src 'none'; style-src 'unsafe-inline'; base-uri 'none'; frame-ancestors 'none'` |
| `/v1/health[?probe=1]` | with `probe=1`: `https://on.substack.com/api/v1/archive?sort=new&offset=0&limit=1`, `https://www.slowboring.com/api/v1/archive?sort=new&offset=0&limit=1` and `https://substack.com/api/v1/top/search?query=substack` (statuses only) | none | `{service:'substack-reader-relay', protocol:1, revision, origin: <request Origin header (≤128 chars) or null>, probes?: [{target:'subdomain'|'customDomain'|'substackCom', status, contentType, challenge, ms}]}` |
| `/v1/archive?host&offset=0..5000&limit=1..25&sort=new\|top` | `https://<host>/api/v1/archive?sort=<s>&search=&offset=<o>&limit=<l>` | 300 / 60 | `ArchivePage`: `publication` comes from `publishedBylines[].publicationUsers[].publication` where `id === publication_id`. `nextOffset = posts.length ? offset + posts.length : null` |
| `/v1/post?host&slug` | `https://<host>/api/v1/posts/<encodeURIComponent(slug)>` | 900 / 300; a 404 is cached 60 s | `{post: PostDetail, publication: PubMeta \| null}` |
| `/v1/post?id=<1..2^53>` | `https://substack.com/api/v1/posts/by-id/<id>` | 900 / 300 | `{post: PostDetail, publication: PubMeta}`, from the response's `publication` (`base_url`/`hostname`); `meta.host` is the publication host |
| `/v1/profile?handle` | `https://substack.com/api/v1/user/<handle>/public_profile` | 3600 / 600 | `Profile`: `subscriptions[].publication` (public only) and `primaryPublication` |
| `/v1/search?q` (2–100 characters) | `https://substack.com/api/v1/top/search?query=<encodeURIComponent(q)>` | 3600 / 600 | `{results: PubMeta[]}` (≤20, deduped by id), taken from `items[type='profileSearchResults'].results[].primaryPublication` and `items[type='post'].publication` |
| `/v1/feed?host` | `https://<host>/feed` | 600 / 120 | raw XML passthrough, `application/xml; charset=utf-8` |

Trimming:
- PostSummary maps from upstream as follows: `id`, `publication_id`, `slug`, `title.trim()`, `subtitle`, `post_date`, `audience`, `type`, `wordcount`, `canonical_url`, `publishedBylines[].name` (≤5) and `podcast_duration`.
- PostDetail adds `body_html`.
- PubMeta `name` is trimmed, because Substack names can have trailing spaces.

Error codes:

| Status | Codes |
|---|---|
| 400 | `INVALID_HOST`, `INVALID_SLUG`, `INVALID_HANDLE`, `INVALID_QUERY`, `INVALID_PARAM` |
| 403 | `HOST_NOT_SUBSTACK` |
| 404 | `NOT_FOUND`, `PUBLICATION_NOT_FOUND`, `POST_NOT_FOUND`, `PROFILE_NOT_FOUND` |
| 405 | `METHOD_NOT_ALLOWED` |
| 429 | `RATE_LIMITED`, with a `Retry-After` header and `retryAfterSeconds` |
| 502 | `UPSTREAM_INVALID`, `UPSTREAM_TOO_LARGE`, `UPSTREAM_ERROR`, `TOO_MANY_REDIRECTS`, `REDIRECT_NOT_ALLOWED` |
| 503 | `UPSTREAM_BLOCKED` (403 or `cf-mitigated: challenge`), `UPSTREAM_RATE_LIMITED` (429, bounded `retryAfterSeconds` of 86400 or less), `UPSTREAM_UNAVAILABLE` (5xx) |
| 504 | `UPSTREAM_TIMEOUT` |
| 500 | `INTERNAL_ERROR` |

Security rules (these keep the relay from becoming an open proxy and prevent SSRF):
1. Callers never supply URLs. The relay builds each upstream URL from a validated param and a fixed path template.
2. **Host allowlist**, checked on every request and every redirect hop:
   - `^[a-z0-9-]{1,63}\.substack\.com$` is allowed.
   - `substack.com` is allowed **only** for the by-id, profile and search templates.
   - Any other host needs a DoH CNAME check: `GET https://cloudflare-dns.com/dns-query?name=<host>&type=CNAME` with `accept: application/dns-json`. Some `Answer` entry must have `type 5` and `data === 'target.substack-custom-domains.com.'`. Cache the verdict for 24 h if it passes and 1 h if it fails.
   - Reject IP literals, `localhost`, `.local`, `.internal`, `.test` and `.invalid`.
3. Every upstream response must have `x-served-by: Substack` or `x-cluster: substack` (case-insensitive). Otherwise discard the body and return `HOST_NOT_SUBSTACK`.
4. Redirects use `redirect:'manual'`, with at most 3 hops. The `Location` must be absolute `https:`, its host must pass rule 2, and the **pathname must be unchanged**. The final host is returned in `meta.host`.
5. Requests are GET only, with no request body and no cookies. Upstream headers are exactly:
   - `User-Agent: SubstackReaderForEvenHub/<version> (+https://github.com/CHL-work/substack-reader-for-evenhub)`
   - `Accept: application/json`, or `application/rss+xml, application/xml;q=0.9` for the feed

   **Never spoof a browser UA or Referer, rotate IPs, or replay `__cf_bm` cookies.**
6. Streaming size caps:

   | Route | Cap |
   |---|---|
   | archive | 1 MiB |
   | post | 4 MiB |
   | profile | 1 MiB |
   | search | 2 MiB |
   | feed | 4 MiB |

   A 10 s timeout applies. JSON routes require `application/json`; the feed route requires `(application/(rss\+)?xml|text/xml)`.
7. Rate limiting:
   - With the binding: `env.RL?.limit({key: `${CF-Connecting-IP}:${route}`})`.
   - Without it (Sites or dev): a per-isolate token bucket of 60 per minute per key.
   - Never log the IP.
8. No `console.log` of hosts, slugs or IPs. Set `observability.enabled = false`. Nothing is stored persistently.
9. Edge cache:
   - Guard with `typeof caches !== 'undefined'`.
   - The synthetic key is built **after** validation, e.g. `https://relay.cache/v1/archive?host=…&offset=…&limit=…&sort=…`.
   - Store fresh `Response`s with `Cache-Control: public, max-age=<edge TTL>`.
   - Never cache 403, 429 or 5xx.
   - `meta.cached` is true on a hit.

## 7. HTML → text conversion rules (implemented by `html.ts`; verified on 6 fixtures and 23 live posts)

| Input | Output |
|---|---|
| Blocks (`p`, `h*`, `blockquote`, list, `pre`, embeds) | Separated by one blank line. List items and tweet lines are joined with a single `\n`. |
| Text nodes | `normalizeChars`, then collapse `[ \t\n\r\f]+` to one space. |
| `em strong b i u mark small span a code kbd cite q time` | Text only. Links lose their URL. |
| `br` | `\n` |
| `h1`–`h6` | Own block; UPPERCASE if 60 characters or fewer (setting). |
| `blockquote`, `div.pullquote` | Each line prefixed `> `. Paragraphs inside the same quote are separated by a `>` line. |
| `ul` / `ol` | Bullets by depth: `• `, `– `, `· `. Ordered lists use `N. ` (honouring `start`). Each nesting level is indented with 3 NBSP. |
| `pre` / `.highlighted_code_block` | A `[Code: lang]` line, then the lines verbatim. Leading spaces become NBSP; the backtick becomes `'`. |
| `hr` | `* * *` (leading, trailing and repeated rules dropped). |
| `sup` / `sub` with digits only | ⁰–⁹ / ₀–₉. Otherwise plain text, and letter subscripts become `_x`. `s`/`del` become `~x~`. |
| Image (`captioned-image-container`, `figure`, `img`) | `[Image: caption]`, then `[Image: alt]`, then `[Image]`. Runs of bare images become `[N images]`. Bare images are dropped by default (setting). |
| Gallery | `[Gallery: N images — caption]` |
| `div.twitter-embed` (`data-attrs`) | `[Tweet by Name (@user)]`, then the tweet as `> ` lines. A quoted tweet becomes `> Quoting @user: …`. t.co links are removed. |
| YouTube / Vimeo / native video | `[Video: YouTube]` / `[Video: Vimeo]` / `[Video]` |
| Spotify iframe / audio | `[Audio: title — subtitle]` / `[Audio]` |
| Embedded or digest post | `[Linked post: Title — Publication]` |
| Datawrapper | `[Chart: title — description]` (a title of "Created with Datawrapper" is ignored) |
| LaTeX (`div.latex-rendered`) | `[Formula: latexToText(expr)]` |
| Poll / code embed / unknown component with no text | `[Poll]` / `[Interactive embed: caption]` / `[Embedded content]` |
| `span.mention-wrap` | `data-attrs.name` |
| Footnotes | `[N]` markers. Bodies go in a `NOTES` section at the end, listing only footnotes that are referenced. Markers whose footnote was cut off by the paywall are dropped. Modes: inline, omit. |
| Dropped entirely | `script style noscript template svg math button form input select textarea source object embed canvas map link meta`, subscribe widgets, `.button-wrapper`, sponsorships, `.image-link-expand`, install-app and community-chat chrome |
| Paywall cut markers (`.paywall`, `.paywall-jump`, `[data-component-name=Paywall\|PaywallToDOM]`, RSS tail `<p><a>Read more</a></p>`) | Stop processing and set `paywalled = true`. |
| `audience !== 'everyone'` | Append `[Preview ends here. The rest of this post is for paid subscribers.]`, or `[This post is for paid subscribers.]` if the body is empty. |

Parser rules:
- Use `new DOMParser().parseFromString(html,'text/html')`. Walk the tree yourself; never use `innerText`, never use bare `textContent` on the body, and never adopt nodes into the live document.
- Classify embeds **before** skipping iframes, because Spotify's component is itself an iframe.

Glyph normalization (applied to every text node, `data-attrs` string and code line):
- **Order:** NFC → delete invisibles → normalize spaces → mapping table → colour emoji → coverage fallback using `getAdvW(cp) > 0`.

## 10. Risks and mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| Substack blocks or challenges Cloudflare Worker traffic. All cross-zone Worker requests share `CF-Connecting-IP 2a06:98c0:3600::103` and carry a `CF-Worker` header, and GitHub-runner traffic to `*.substack.com/feed` already gets 403 while custom domains get 200. | No content | `/v1/health?probe=1` runs right after deploy, and the error is shown honestly (`UPSTREAM_BLOCKED` with upstream status). The client retries via the feed route. The same bundle can move to another host (Sites, Deno Deploy, Vercel) with no code change. Optional rss2json fallback behind a build flag. **Never spoof.** |
| Shared-IP 429s from Substack | Intermittent failures | Edge cache (archive 300 s, post 900 s), client HTTP cache, at most 2 concurrent requests, no prefetch, and `Retry-After` is respected and surfaced. |
| Substack ToS: no scraping and no storing "significant portions" | Takedown or legal | Fetches happen only on user action, one at a time. No server storage and no persistent device text cache. Honest UA. Attribution ("on Substack"). Copy link to the original. Owner decision on store distribution. |
| Undocumented API changes (fields, `top/search` schema) | Broken lists or search | Defensive normalizers. Search falls back to "paste a link". The feed fallback covers recent posts. Fixtures make breakages obvious. |
| Event routing differs (sys vs text vs list); CLICK arrives with no type | Dead taps | `mapEvent` reads all three envelopes. Diagnostics shows raw events, so the owner can capture real routing. |
| Swipe direction unverified | Inverted paging | "Invert swipe" setting; recorded on the device checklist. |
| Body overflow makes the firmware scroll internally | Two swipes per page | `isReaderPage` guard, pretext pagination, every frame body paginated, 1800-byte cap. |
| Phantom scroll after writes, or multiple events per swipe | Skipped pages | `input.ts` filter (300/50/80/220/600 ms). |
| Browser `localStorage` not persisted in `.ehpk` | Lost publications | Bridge storage is the source of truth; `localStorage` is a mirror; the newest `savedAt` wins. |
| Bridge storage size limit unknown | Save failures | Two keys, each 48k characters or less, with eviction; the phone shows a "Could not save" message. |
| Missing glyphs | Garbled text | `normalizeChars` with an exact `getAdvW` coverage test; on-device glyph check. |
| Relay origin is baked in at build time | A relay move needs a new `.ehpk` | Use a stable origin (a custom domain is preferred); `pack.mjs` and CI checks prevent mismatches. |
| Android WebView killed in the background, or iOS lock | Lost place, or a spinner | Flush position on background and pagehide, cold-start resume, 15 s timeouts, and a frame rendered before every await. |
| Store review: name, privacy, icon, root exit | Rejection | No "Even" in the name. Root double-tap calls `shutDownPageContainer(1)`. Greyscale icon. Privacy policy at `/privacy` names the relay domain. Use of "Substack" in the name is an owner decision. |
| Toolchain drift (TypeScript 7, Vite 8, pnpm 12) | Broken builds | Exact pins, a committed lockfile, `--frozen-lockfile`. |
| CSP not set | Weaker defense in depth | Post HTML never touches the live DOM and the phone UI escapes every value. Add a CSP later once its interaction with the bridge is verified. |

## 11. Decisions for the owner

See the structured list in the final report. In short:
- relay host (Cloudflare or Sites) and its origin (a custom domain is preferred);
- app name and package id ("Reader for Substack" / `com.chlwork.substackreader`), and whether "Substack" may appear in the name;
- paid content via the user's cookie (recommended: no);
- the rss2json fallback (default off);
- an on-device offline text cache (default none);
- a phone "read on glasses" push button (default none, following LIHKG 0.3.0);
- the gesture scheme (default: Even convention, double-tap = back);
- Beta only, or public submission;
- whether the CI-only test rule still applies;
- whether to upgrade the toolchain.
